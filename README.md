## How to Run

1. Install the **Java Development Kit (JDK)**.
2. Clone or download this repository.
3. Open the required project in your preferred Java IDE.
4. Locate the main Java class containing the `main()` method.
5. Compile and run the program.

Example:

```bash
javac Main.java
java Main
```

> The exact class name and commands may differ depending on the project.
